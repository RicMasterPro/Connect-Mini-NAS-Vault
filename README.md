# Connect-Mini-NAS-Vault
Connessione ad uno spazio di archiviazione di rete sempre a portata di mano.



## File disponibili
- Il file .exe compilato: Può essere eseguito subito senza alcuna configurazione.<br>
È la scelta ideale se vuoi usare lo script così com'è, attivando immediatamente tutte le funzionalità.

- Il file .bat originale: Contiene tutto il codice sorgente dello script.<br>
È perfetto se desideri personalizzare comportamenti, modificare o aggiungere nuove funzionalità.<br>
Dopo aver apportato modifiche, puoi eseguire lo script tramite Prompt dei comandi e ricompilarlo in un nuovo file eseguibile.



## Funzionalità
- IP Address: L'indirizzo IP dell'archivio di rete<br>
- Device Name: Il nome della risorsa di rete a cui accedere<br>
- Username: Il tuo username per accedere<br>
- Password: La tua password per accedere<br>



# Note tecniche
Le credenziali vengono gestite in modo sicuro per evitare che vengano mostrate in chiaro.<br>
Alla pressione di un tasto dopo l'utilizzo, la connessione di rete viene rimossa per una maggiore sicurezza.
